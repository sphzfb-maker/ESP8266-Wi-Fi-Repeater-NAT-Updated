ESP8266 Wi-Fi Repeater v1.2.2

This source package targets a 4 MB ESP8266 flash layout and contains the
updated mobile web UI, hidden-network scan support, diagnostics, WAN
reconnect, internet reachability test, and traffic-counter reset.

No prebuilt .bin is included in this source ZIP. Build with PlatformIO:
    pio run

The resulting firmware is:
    .pio/build/esp12e/firmware.bin

For a 4 MB target, the supplied flash scripts use:
    --flash_size 4MB

After flashing, connect to:
    ESP8266-Repeater-Setup
and open:
    http://192.168.4.1
